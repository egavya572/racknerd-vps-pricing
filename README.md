## 常见问题

### 国外云服务器需要备案吗？

不需要。国内服务器托管网站要走 ICP 备案，国外服务器没有这道流程，购买后解析域名即可上线，这也是很多人选国外机器的首要原因。

### VPS、虚拟主机和独立服务器怎么选？

虚拟主机是把一台物理服务器分隔成多个共享资源的主机，便宜，适合托管个人网站，但性能有限、多为共享 IP。VPS 的 CPU、内存、存储完全独立分配，能当一台独立服务器用，自建环境、跑业务都可以。独立服务器整机独享，适合大流量业务和站群。个人建站从 VPS 起步，跑起来后再按需升级。

### RackNerd 支持支付宝吗？

支持，同时接受银联、PayPal、信用卡和多种加密货币，下单无需实名认证。

### 年付还是月付？

用途确定的长期业务选年付，单价最低；没定下来或只做短期测试，选月付，或者找 Vultr 那种按小时计费的方案。顺带留意各家的反悔窗口：萤光云给首个订单 5 天无理由退款，Interserver 支持 30 天无条件退款，RackNerd 的退款条款下单前到官网确认一遍。
